# 确定桌面首发是否跳过内测以及承诺级别

正式决策票：[确定桌面首发是否跳过内测以及承诺级别](https://github.com/IceFireIcer/DS-SuperAgent/issues/200)。类型：`wayfinder:grilling`。状态：已关闭。

## Question

该发布规划是否组织任何内测或邀请制试用阶段？若否，选公开预览还是直接稳定首发？注意：不组织内测不自动意味着跳过发布门槛；需要依据所选首发承诺定义候选包、证据和放行责任。

## Resolution

Windows x64 首发为公开预览：发布后任何人可下载，不设内部或邀请制内测、邀请码或反馈义务。公开预览承诺桌面对话与本地项目工作，Main 半双工作为已知限制。该承诺不是稳定版，也不代表当前候选已获准发布。
