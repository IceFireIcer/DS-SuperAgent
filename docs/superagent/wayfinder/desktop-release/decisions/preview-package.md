# 确定 Windows x64 首发形态、分发与回滚边界

正式决策票：[确定 Windows x64 首发形态、分发与回滚边界](https://github.com/IceFireIcer/DS-SuperAgent/issues/196)。类型：`wayfinder:grilling`。

## Question

公开预览已定：Windows x64 包发布后任何人可下载，不设内测、邀请码或反馈义务；公开预览不等于稳定版承诺，也不代表当前候选已经放行。在此承诺下，包形态、发布途径、版本标识、安装/升级/回滚与产品数据保留规则应如何安排，才能安全易用且不触碰用户个人 DSH 数据？

## Resolution

- 通过官方 GitHub Releases 公开分发 Windows x64 预览包。
- 版本标识包含预览阶段、版本号与对应提交 SHA，便于识别候选来源。
- 客户端可自动检查并下载更新；安装更新前必须由用户确认。
- 更新不得删除产品数据或用户自行选择的项目文件；产品数据格式迁移前先备份。
- 若更新失败，回滚到上一个可用版本。任何路径都不得写入用户个人 DSH 数据。
