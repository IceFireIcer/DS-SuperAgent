# 确定 Worker 跨项目目录工作的授权与拒绝规则

正式决策票：[确定 Worker 跨项目目录工作的授权与拒绝规则](https://github.com/IceFireIcer/DS-SuperAgent/issues/199)。类型：`wayfinder:grilling`。

## Question

项目文件夹是 Worker 的起点，不是唯一可工作的目录。任务需要读写项目外目录时，什么算用户授权，授权范围和期限是什么？若用户拒绝或未授权，该工作如何暂停、缩小范围或继续？优先沿用已有能力，仅对不足部分考虑补偿，不假设当前实现已经验收。

## Resolution

用户明确授权的路径和操作仅对当前任务有效，受派执行该任务的多个 Worker 可以共用这份授权。若需要访问其他路径或执行未获授权的操作，Main 必须先询问用户；确认前不得执行超出范围的步骤。用户拒绝时，只跳过依赖该授权的步骤，其余步骤继续。任务结束时授权失效。
