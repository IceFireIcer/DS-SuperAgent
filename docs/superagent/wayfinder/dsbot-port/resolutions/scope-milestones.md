# 确定首版与全量 C 域范围及里程碑：决定

对应决策：[确定首版与全量 C 域范围及里程碑](https://github.com/IceFireIcer/DS-SuperAgent/issues/136#issuecomment-7001661411)。

## 结论

1. SuperAgent 是 DS-Bot 的核心换血。DS-Bot 最新代码、功能与 UI 整体搬入并适配 `/api/product`，`temp\DS-Bot` 原样不动。
2. 排除与旧核心绑定的页面/能力：Bot 列表/创建/编辑、Bot 模型、头像库、群聊/群设置/群搜索、本地 Agent、团队权限。
3. 保留：成员状态、任务板、连接器（飞书/GitHub/邮箱）、IM（含飞书账号登录与收发）、手机/link、浏览器、电脑操控、能力/MCP、定时任务、用量、密钥、记忆、内置插件、Agent 预设、反馈、关于、通用、模型。
4. 不一次性锁总人日；由用户逐步实现、按域放行。
5. 三段：
   - ① 全量 UI 外壳 + 聊天闭环 + 通用/模型/关于等基础设置；
   - ② 连接器、IM、手机/link、浏览器、电脑操控、能力；
   - ③ 定时任务、用量、密钥、记忆、预设、反馈及收尾。
6. 未接线动作 fail-closed 是过渡，不是永久范围缩减。
