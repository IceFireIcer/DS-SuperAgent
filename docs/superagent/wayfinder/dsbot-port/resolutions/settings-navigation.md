# 确定设置导航树与冲突页归属：决定

对应决策：[确定设置导航树与冲突页归属](https://github.com/IceFireIcer/DS-SuperAgent/issues/137#issuecomment-7002657214)。

## 最终导航

1. **通用**：通用（外观）
2. **模型**：模型、角色、Agent 预设、内置插件
3. **连接与能力**：连接器、IM、手机、浏览器、电脑操控、能力库
4. **SuperAgent**：执行策略、定时任务、主动准备、监督、记忆、用量、密钥、远程客户端
5. **帮助**：反馈、关于

## 冲突页

- 浏览器：浏览器资源 | 浏览器插件
- 定时任务：日程 | 定时任务
- 用量：用量 | 状态（更新/备份/诊断）
- 密钥：密钥 | 凭据资源

## 其他

- 角色与模型分开：模型页管 Provider/目录/发现/key；角色页管 Main/Router/Worker 配置。
- 成员状态在 Main composer 上方 dock；任务板是 `conversation.view` 的 Work 视图；设置无入口。
- `客户端授权` 改名 `远程客户端`。
- 排除页完全不渲染。
