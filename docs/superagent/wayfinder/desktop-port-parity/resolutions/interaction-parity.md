## Resolution · 桌面动效与键盘验收

维护者看过新版样板并确认验收口径。样板以本地 DS-Bot v0.3.8（`5e9b7da8`）的交互为参照，在 DS SuperAgent 界面中用隔离数据演示五条路径。[新版离线样板](../prototypes/desktop-interactions.html)

### 逐路径必验

- 用键盘完成每条适用路径。`Tab` 顺序跟随界面，焦点可见，菜单支持方向键。`Esc` 只关闭最上层弹层。支持点击外部关闭的弹层也要检查这一关闭方式。关闭后焦点回到入口，入口已消失时回到下一处可用控件。
- 空态、忙态和失败都有可读反馈。输入区的附件、单次听写、发送、停止、连续语音和问题卡随实际状态切换。角色状态和启动失败可直接辨认，交接到 Main 后可立即输入。
- 普通动效对照 DS-Bot 的按钮切换、菜单和对话框进退场、角色状态及启动交接。减少动态效果时，角色停止动画，菜单即时进退，对话框可仅淡入，启动交接直接到位。两种模式都能完成同一操作并得到反馈。[DS SuperAgent UI 设计标准](https://github.com/IceFireIcer/DS-SuperAgent/blob/50491ff160ccf1a5bc86226d52d2a3e0162ed31f/docs/design/ui-standard.md#9-动效)

### 视觉抽验

将目录与输入框、账户与模型、连续语音与问题卡、角色与工作状态、启动交接与失败重试分配到代表性组合。覆盖窄窗和宽窗，以及 DeepSeek、Mono、Paper、Moonlight 的浅色与深色，共 16 种组合。检查焦点可见、弹层在可见范围内、内容无裁切和同路径进退场。

离线样板的 Chromium 检查覆盖五条模拟路径、焦点返回、逐层 `Esc`、减少动态效果和 16 种组合的菜单布局。产品验收使用同一候选提交的远端完整 CI 和桌面构件证据。[确定独立桌面验收的证据与门槛](https://github.com/IceFireIcer/DS-SuperAgent/issues/168#issuecomment-7055697055)
