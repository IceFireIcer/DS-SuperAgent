## Resolution · Main 连续语音的暂停与恢复

维护者确认复用 DS-Bot 0.3.8 的 `VoiceMode` 界面和「收听 → 提交 → 朗读 → 续听」。转录通过原 Main 的持久化提交路径发送，按提交回执匹配本次完整回复，正常朗读结束后续听。界面显示收听、等待回复、朗读和暂停状态。[核对桌面用户路径与实际接线](https://github.com/IceFireIcer/DS-SuperAgent/issues/166#issuecomment-7055595551)

- 手动暂停、出现问题卡、停止当前 Main 回复、最小化或隐藏窗口时，立即释放麦克风、停止朗读并使迟到的转录失效。问题卡接管输入位。回答问题或回到可收听的窗口后，由用户点「继续」恢复收听。
- 麦克风权限被拒或发送失败时显示原因，等待用户操作再试。单独停止后台工作时，连续语音仍按当前 Main 回复的状态运行。
- 切出 Main、关闭语音面板或关闭窗口时结束连续语音并清理音频。回到 Main 后由用户重新开启。

实施验收覆盖正常续听、上述暂停与退出、迟到转录和发送回执，以及附件、单次听写、发送和停止的原有路径。[确定独立桌面验收的证据与门槛](https://github.com/IceFireIcer/DS-SuperAgent/issues/168#issuecomment-7055697055)
