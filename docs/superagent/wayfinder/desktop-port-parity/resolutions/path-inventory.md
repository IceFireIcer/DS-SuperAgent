## Resolution · 桌面用户路径与实际接线

本票完成源码盘点，不是桌面验收。上游为本机 `temp/DS-Bot` 的 [`v0.3.8`](https://github.com/Fei2411/DS-Bot/tree/5e9b7da8882da3b68d8a0624342708c2150a9156)，产品为 [`dev` `50491ff1`](https://github.com/IceFireIcer/DS-SuperAgent/commit/50491ff160ccf1a5bc86226d52d2a3e0162ed31f)。图号按方案里的文字描述定位，没有重新截屏或运行桌面包。

`sync-client.mjs --check` 核对了 126 个客户端源项加 5 个共享依赖，131 份本地同步产物一致。下列上游 `sidebar.js`、`folder-menu.js`、`model-menu.js`、`composer.js`、`voice.js`、`surface.js`、`motion.js`、`opening.js` 均有普通模块快照；上游 `index.js`、`overlays.js` 和 `settings-shell.js` 是仅供参考的快照。快照在忽略目录，不是产品的导入或挂载证明；产品入口仍是 `applyProduct`。

### 桌面桥与窗口（图外）

- **启动与窗口**：上游 [`StartWindow`](https://github.com/Fei2411/DS-Bot/blob/5e9b7da8882da3b68d8a0624342708c2150a9156/app/src/start-window.mjs#L625) 用页面绘制和 `handoffShow` 协调交接，带超时退路；产品 [`showStartupWindow` 和主窗交接](https://github.com/IceFireIcer/DS-SuperAgent/blob/50491ff160ccf1a5bc86226d52d2a3e0162ed31f/app/src/main.mjs#L1082) 已有状态窗、显示主窗后收掉、托盘唤回和失败路径。未对等的是上游启动过渡，不是要重建 Host 生命周期。启动、慢加载、失败、唤回的动效证据归交互样板；自然退出、下载更新、安装后重开归发布证据。
- **选择器、通知、下载、日志**：上游 [`Pickers` 和页内卡](https://github.com/Fei2411/DS-Bot/blob/5e9b7da8882da3b68d8a0624342708c2150a9156/app/src/picker-host.mjs#L14) 不等同于产品已选用的原生选择器；[桌面壳实施记录](https://github.com/IceFireIcer/DS-SuperAgent/blob/50491ff160ccf1a5bc86226d52d2a3e0162ed31f/docs/superagent/implementation/client-port-phase-two.md) 已记录这个替换与数据隔离。产品已有桌面 picker IPC、通知点击唤回、下载回执和 Status 日志，保留桥并复验取消/拒绝/失败，不为外观一致再引入一套文件授权与旧导入。
- **真实环境待验**：发布矩阵、真实模型、电脑指示器与真实 OAuth、邮箱、IM、外部 MCP 都不能用源码或模拟试用代替；由[确定独立桌面验收的证据与门槛](https://github.com/IceFireIcer/DS-SuperAgent/issues/168) 区分归属。手机、旧 Bot/群/Local Agent、团队权限不纳入。未发现需要新增决策票的其他窗口或桥缺口。

本次仅跑同步产物一致性检查，未启动 Host、运行产品测试、登录真实账户或修改产品代码。
