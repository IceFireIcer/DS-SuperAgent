# 保护 Roles 未保存的更改（#189）

Roles 有未保存的更改时，关闭按钮、遮罩、Esc、表单取消、侧栏、搜索结果和设置快捷入口都经过同一个确认。默认焦点落在「继续编辑」，选择后保留输入和当前页面，并把焦点交回触发控件。放弃更改后执行原先请求的关闭或跳转。

保存使用草稿对应的配置版本。发生版本冲突时，重新读取最新配置并合并改过的字段，等待用户审核并再次保存。供应商、模型 ID 与思考强度共同表达一次模型选择，合并时保留该选择的完整性。

在 Windows Node 24.22.3 下通过定向测试、类型检查、构建和生成客户端检查。隔离 Edge Chromium 中以实际 Host 产生配置版本冲突，确认 Tab 在确认框内循环、Esc 恢复编辑焦点、搜索跳转保留草稿。浏览器确认重新合并只是读取，随后显式保存的回执和 Host 持久读取一致。
