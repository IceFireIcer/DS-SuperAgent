# R5-07：在主对话直接回答当前问题卡

- 工单：[R5-07 / #99](https://github.com/IceFireIcer/DS-SuperAgent/issues/99)。
- 前置：[R5-02 / #94](r5-02.md)。
- 日期：2026-11-15；实现位于 `dev`，未发布。

## 交付行为

Main 工作卡现在展示 Worker 当前 Attention 的 work item、Ticket、Assignment generation、问题版本、选项、自由输入权限及回答状态。公开产品协议 `work-answer` 才能从卡片提交答案，必须同时携带精确 `workItemId`、`ticketId`、generation、`attentionId`、Attention version 和有界正文。

Engine 在同一授权入口重验 Instance、逻辑 Main、WorkBrief、receipt、Ticket、当前 Assignment 和 Attention version，然后把回答写入原 Ticket 的稳定 synthetic Input。同 command 同文重试返回原输入；异文返回 `IDENTITY_CONFLICT`；过期版本、旧 generation、错误 actor 和已完成问题被拒绝。回答事实写入 `work-update` 并在工作卡及只读观察中显示，不依赖 Main 模型转述。

Attention 仍按原 Assignment/Session 继续。显式 stop 会将该 Ticket 的等待问题标为 `superseded`，保留原问题和 `previousConstraint` 作为历史；stop 后的直接 Attention ID 或 Main 卡片答案返回 `TICKET_STOPPED`。非停止状态下，正常答案由原 Worker continuation 消费；显式 resume 不复用已停止的问题作为答案。

观察页仍只能返回 Main 处理；卡片的回答入口只在当前 waiting Attention 且权限允许时出现。一项 waiting-human 不阻止其他 Ticket，跨代次或被停止的问题不能借旧 ID 回答。

## 验证

- Main 卡片集成：读取当前问题/版本/选项，错误 actor、旧版本和旧 generation 均拒绝；合法答案持久、稳定重试去重、异文拒绝，回答事实在卡片和观察中可见；stop 后回答返回 `TICKET_STOPPED`。
- Attention 回归：正常答案继续同一 Assignment/Session；stop 将问题终结为历史状态并拒绝晚答；普通跟进、重复问题、来源 actor 隔离和交付竞态保持。
- Native Shell：定向 fixture 等待原生 turn 静默并 flush 后，从 stable message ID 补认持久输入；持久回执仍由有界 deadline 约束。
- 定向串行测试、Super-agent typecheck/build/lint 和 DS Bot 生成/边界检查结果见最终提交说明。

## 边界

本票没有引入替代主对话 UI、原生 Session 写旁路或“最近 Worker”兜底。真实模型语义质量、外部信道组合和完整四目标验收仍由汇总票负责。
