## 交付行为

Outbox 继续是唯一外发入口。acknowledgement、answer、attention 和 result 分别在派发前重新核验原请求、当前人类问题及 Worker fact、当前结构化 Attention、当前 ready report/Assignment，并核对精确目的地。Router 与 Worker 只能提交已有的类型化事实；跨受众结果仍要求当前、获授权且已关联的原生事件，永久失败不会自动改投或广播私人内容。

Delivery 查询现在明确区分 `pending`、`sent`、`dropped` 和 `unknown`。平台已接收但响应丢失的 Effect 不再伪装成 `pending`；返回 `reconcileRequired: true`、原因和尝试次数。Engine 新增 `reconcileDelivery({ commandId, ticketId, deliveryId })`，只使用该 Delivery 的原 Effect generation 和 idempotency key 调用信道对账。相同命令重放不会再次发送；临时失败仍按既有有界退避恢复，永久失败仍是 `dropped`。
