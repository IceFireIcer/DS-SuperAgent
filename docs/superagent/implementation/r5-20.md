## 已接通的行为

桌面 Host 原有 Office payload 完整时，产品 profile 将其 Node、已打包的 `ds-bot/office.js` 和 Office 技能目录交给每个本地工作目录的 Environment；缺任一文件时不声明可用。Worker 可在绑定的本地 Environment 列举并读取技能，使用 `stage_attachment` 把本工作项获准的原始 `.docx` 字节复制到工作目录中的新路径。跨工作项、跨 Environment 或已撤销的上传由原授权检查拒绝；已有目标文件不能被静默覆盖。

Worker 使用相同 Environment 中的公开 DSH subprocess 接缝执行现有 Office CLI 的 `docx-read`、`docx-edit`（另存新文件）和 `check`。Office 工具只接受受控操作及目录内相对路径，不提供模型任意 CLI 参数。文件结果继续由 `report_ready` 记录真实 SHA-256、字节数、Environment 引用和相对路径；报告前必须有成功的 Word 检查，并在提交报告时重新检查实际产物与摘要。主对话现有工作卡展示产物，产品本地入口按原工作归属和 Environment 身份逐页读取/下载。重复上传沿用原命令 ID 回执；路径错误、命令失败、取消与退出不可确认均不换执行世界重试。

## 定向验证

Node 24.22.1、隔离临时目录、虚构授权角色、仓库自带 `.docx` 样例及本地 Office CLI：产品上传 → Worker 技能发现 → 授权附件落盘 → 结构读取 → 定点编辑为新 `.docx` → 包检查 → 持久工作卡 → 产物逐页取回并核对摘要和正文；猜测产物路径与工作项被拒绝。另测跨 Environment 附件、越界路径和无效 Word 包拒绝。相关 `product-office`、`product-attachments`、`capability-locations` 定向回归 16/16；Super-agent build、typecheck、lint 与 UI boundary 检查通过。没有运行全量 CI、真实 Office 服务或个人资料。

## 2026-11-17 结构化视图与答复收口

- 本轮基线：`origin/dev` `fa63b066`；均在 `dev` 工作树增量实现。

Super-agent 直接复用现有 `deep-view` 0.1.0 校验、规范化和现有 `WidgetCard`，不另建 renderer。`report_ready` 可携带一个不超过 8 KiB 的只读视图 `{ title, view }`；含 options/confirm/form/submit 的交互蓝图会被拒绝。校验后的规范化蓝图经当前 Environment 的脱敏处理（隐藏凭据模式和实际工作目录）再随 ReadyReport 持久，并投影到 Main 工作卡和 WorkOutcome，文件产物仍按原 SHA-256、字节数、Environment 引用与工作归属生成；只写说明或没有真实报告文件不能成为完成结果。

本地产品 Worker 另有 `show_view`：只接受含交互组件的视图，在联系用户前验证并脱敏完整蓝图，再建立与 Attention 同一持久等待约束。该记录继续绑定 Ticket、workItem、Assignment/代次和 Session；Worker 回合结束并释放槽。Main 工作卡显示可提交的现有视图组件。`work-answer-view` 只接受当前 Main、精确 workItem/Ticket、当前 Assignment 代次、当前 Attention 版本和原蓝图允许的 action/values；答复字符串同样先脱敏再持久。失败不消耗视图，成功才把 view answer 事件连同 `answerView` 持久并恢复原 Worker。相同命令重放返回原 Input，旧版本、错误代次、越权或非法选择拒绝。远端客户端只有在 `command` capability 下才能命中该命令路由；只读客户端收到授权拒绝。只读 WorkOutcome 或无权答复的工作卡没有提交入口，交互视图答复与只读预览在协议和 UI 上分开。

`show_view` 只向 `product-desktop` 工作开放，其他来源不会收到无法从其信道回答的交互卡。视图答复不会改变执行世界、重派 Ticket 或调用外部文件操作；Office 缺能力、路径越界、重复、取消和 unknown 继续沿用原 Environment 的封闭行为。

Node 24 最终定向回归 36/36，覆盖 Office/视图、Attention、工作观察、产品附件/执行、client gateway、能力位置与 retry/unknown；DS Bot 工作卡/远程等待/i18n/样式 8/8，app 三包 `deep-view` 版本一致性 1/1。真实 `.docx` 样例完成上传、授权落盘、编辑、Office 检查、报告视图、产物分页读取与摘要核对；交互视图覆盖只读蓝图进入 `show_view` 被拒绝、交互蓝图进入完成报告被拒绝、工作目录/凭据脱敏、空选择与错误代次拒绝、成功恢复、同命令重放、完成后旧命令拒绝和只读视图无提交按钮。`npm ci --ignore-scripts`、Super-agent build/typecheck/lint、DS Bot client 生成一致性、UI boundary 和记录检查通过。没有运行全量 CI。

真实 Electron 视觉检查、真实模型选择视图的意图质量、PostgreSQL 专项和多格式 Office 渲染仍未单独验收；这些不否定已通过的 Engine、mock Host 和现有组件代码路径。真实飞书租户按既定决定继续暂缓。
