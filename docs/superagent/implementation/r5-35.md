# R5-35 独立安装包与冷启动

[GitHub #127](https://github.com/IceFireIcer/DS-SuperAgent/issues/127) · [R5 规格](../spec-r5.md) D07、D10、D11，A14、A22–A24 · [复核](reviews/r5-35.md)

- 桌面显示名为 DS SuperAgent，应用 ID 为 `io.github.icefireicer.ds-superagent`，分发资产用 `DS-SuperAgent-*`。Linux 命令和 deb 使用 `ds-superagent`。Windows 从新应用 ID 派生安装 GUID，后续 DS SuperAgent 更新沿用自己的程序目录。
- 首次启动直接进入 Main。默认业务数据在 `~/.ds-superagent`，工作区在 `~/DS SuperAgent`，桌面设置使用自己的 `DS SuperAgent` 目录。Host 运行唯一的 `ds-superagent` profile，通过公开的 `@deepseek-ai/dsh/profile-boot` 挂载固定版本 DSH 和生成的现有客户端。
- 已保存目录失效后回到原生目录设置，可恢复目录或写权限，也可显式换目录。缺少角色模型时，Main 指向现有设置。模型调用失败时可在同一设置检查模型与服务商凭据。
- 产品使用 `DS_SUPERAGENT_*` 启动变量，并避开个人 DSH 和旧 DS Bot 的数据目录。独立安装身份保留原有 DS Bot 程序和资料。安装与卸载沿用现有流程。
