# #180 启动交接与失败重试

启动窗口显示启动进度或失败原因。`Try again` 在原窗口重新启动同一产品 Profile，恢复回滚和退出动作继续沿用原生命周期。失败页面的动作仅由当前启动窗口的主框架发送。Main 输入可用后交接到已创建的桌面窗口，保留弹层当前的焦点。普通模式采用上游 `StartWindow` 的 220 ms 透明度交叉淡入淡出，系统减少动态效果或产品安静模式直接交接。

| 验证环境 | 结果 |
| --- | --- |
| Windows，Node 24.22.3，`npm test`（`app/`） | 254 通过，1 项 Linux 专用测试跳过。生命周期夹具验证同窗重试、不受 Main 窗口 IPC 触发、重复动作不重复启动、恢复回滚、常规淡入淡出和减少动态效果。 |
| 本机 Windows Electron 44.7.0，独立 Profile 和 mock 模型 | 用隔离 Host 锁夹具触发启动失败。1320 px 普通模式和 508 px 减少动态效果下，原因和重试按钮均可见且有焦点环。按 Enter 原窗重试，原 Main 窗口取得输入焦点，键盘发送并收到对应回复。 |

两次窗口试验结束时均按探针的短清理时限回收进程，安装和升级退出结果由候选包验收记录。
