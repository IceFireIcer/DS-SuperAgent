本增量在新产品业务库中保存 Main、单个工作私有、明确共享三种记忆。工作私有记忆只在对应工作取得用户授权且 Assignment 仍有效时供 Worker 查询；共享记忆只供明确列出的 Main 或工作读取。Main 无权读取工作私有记忆。查询只给有界命中摘要；全文按 UTF-8 字节分页，在每页读取时重新查权限和版本。查询不会自动产生长期记忆。Worker 子代理继承原 Assignment 的有界记忆工具；旧 Bot 的群记忆与聊天历史工具没有接入新产品。

Main/Worker 的学习工具只创建十分钟内有效的待审提案。用户在现有设置页审阅并批准或拒绝；审批时再次核对当前 Main Session，或 Worker 的 Assignment、工作记忆 grant 代次和过期时间。用户也可直接保存一条事实、明确设置共享接收者、撤销工作读取权或遗忘。撤权后的后续搜索与全文读取被拒；遗忘删除可检索原文、保留无原文墓碑和命令指纹。已写入历史 Session 的合法原始依据并未篡改，已经送入模型的内容也无法追回。新产品 HTTP 只让本地已授权设置入口管理记忆，远端客户端在服务端拒绝。

SQLite 与 PostgreSQL 均沿用现有通用 `RecordKind`/`Storage` 事务协议；只增加四个记录种类，没有专有表或 SQLite 专用 SQL。Node 24.22.1、TypeScript 6.0.3：定向 `product-memory`、`main-conversation`、`execution`、`transaction-contract` 共 17/17 通过；TypeScript 检查、前端生成一致性及 UI 边界检查通过。测试用临时 SQLite、虚构身份和 mock DSH，不含真实个人资料。

未完成：#107 的通用资源凭据授权与可选旧记忆导入仍有独立前置；本票未证明真实模型的跨月召回质量、生产 PostgreSQL 集成、真实 Host/多进程撤权时序或 DSH 原生 Session 中已读取内容的追溯删除。这些不能以局部测试替代完整验收，#113 不关闭。

## 2026-11-16 side query 范围补齐（`dev`）

设置页的普通 `memory-list`/`memory-read` 是本地用户管理视图，可管理本 Instance 内的 Main、工作私有和明确共享记忆。角色的 `search_memory`/`read_memory` 是受授权召回。新增的 side query 是记忆设置页内独立的只读检索和原文分页入口，不创建另一条对话，不调用模型，不写入 Main/Worker Session，也不把检索命中自动保存为长期记忆；它不复用旧 `side-ask` 或 `memory-ask`。

side query 经 `memory-side-query`/`memory-side-read` 从本地 Host 转到 Engine 的公开方法，再由 `ProductMemory` 在同一次 Storage 事务内解析当前 Main Session 或指定工作项的当前 Ticket/Assignment。窗口只传 `{kind:'main'}` 或 `{kind:'work',workItemId}`，不能指定 Session、Assignment、Ticket 或冒充角色。Main 只查自己的和明确共享给 Main 的条目；工作查询只查该工作私有和明确共享给该工作的条目，并要求当前 Assignment 正在运行、Ticket 有效、工作授权仍启用。搜索最多返回 20 个命中，扫描上限为 1000；原文每页 256–4096 UTF-8 字节。每一页都重查当前授权、归属与条目版本；撤权、换代、移除共享、遗忘或修改版本阻断后续读取。远端客户端仍在 Host 被拒绝。

本轮在虚构身份及临时 SQLite/mock DSH 环境用 Node 24 验证：Super-agent 构建、TypeScript 检查、`product-memory.test.mjs` 6/6，DS Bot `product-memory.test.js` 1/1，并检查前端生成一致性和 UI 边界。覆盖跨 scope 隔离、拒绝未授权工作、撤权后读页、Assignment 失效、分享变化/游标失效、遗忘和远端 Host 拒绝；UI 测试验证目标切换、检索、分页及切换 Instance 后旧异步结果不会显示。角色查询/全文读取只向 Worker 返回当前工作项的共享范围视图，不暴露其他共享接收者。原有 `read_own_chat`/`read_group_chat` 旧入口仍存在于旧产品，计划在 R5-34 收口，不能据此声称本票已完成该验收项。生产 PostgreSQL、多进程撤权时序、真实模型/真实设备、跨月质量与 #107 前置仍待独立验收；#113 保持开放。
