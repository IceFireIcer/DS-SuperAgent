# 在窄窗中搜索和打开设置（#188）

设置弹窗支持中英文页面名、页签名和任务关键词。搜索 `backup` 或「备份」会找到 `Usage › Status`。结果按稳定页面 ID 打开，查询为空时显示完整的五组导航。搜索索引来自设置导航元数据，可用性遵循当前页面配置。

低于 720 CSS 像素时，通过带文字的按钮打开页面选择区。选中结果或按 Esc 后，焦点回到选页按钮。调整窗口宽度时保留搜索词。设置正文独立纵向滚动，用量热图提供可聚焦的横向滚动区。

## 验证

- Windows Node `24.22.3` 下通过 32 项定向测试，覆盖 settings shell、设置入口、模型引导、用量和翻译。类型检查、构建、生成客户端检查及改动文件 lint 通过。
- 隔离 profile 的 Edge Chromium 探针通过。覆盖宽窗、720 断点两侧、508×480 及代表缩放视口，验证 Tab 与 Enter 选择结果、清除查询、焦点返回、布局边界及热图独立滚动。一次运行在 Main 挂载前超时，复跑通过。
- Windows Electron 44.7.0 的隔离窗口载入同一产品 profile，按桌面应用的最低窗口参数验证搜索路径。实际内容视口为 1120×760、721×600、719×600、508×482，以及 150% 缩放时的 338×321 CSS 像素。使用本地 Electron 探针验证窗口和缩放，安装包候选验收见 #192。
