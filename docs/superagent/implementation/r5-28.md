## 安全边界

R5-15 记录的 DSH 公开 `CredentialKey` record API 只按已知引用读写，不提供安全枚举旧 vault 的能力。此实现不遍历 DSH credential records，不读取安装内部文件，不读取或写入用户的 `~/.dsh`，也不通过 `.env` 或 ambient `CredentialRef.resolve` 回退。桌面应用只在用户明确选择 JSON 文件后读取它；文件原件保持不变。不能安全取得的旧凭据需要在凭据资源页手动重新配置。

接受 `ds-superagent-credential-export` v1 JSON，最大 1 MiB、最多 50 项。示例只使用虚构值：

```json
{
  "schema": "ds-superagent-credential-export",
  "version": 1,
  "origin": { "label": "Legacy profile", "instanceId": "legacy-instance" },
  "credentials": [
    {
      "id": "service-key",
      "label": "Example service",
      "type": "api-key",
      "value": "fictional-value",
      "originalScope": { "kind": "work", "role": "Legacy Worker", "work": "Old task" }
    }
  ]
}
```

类型为 `api-key`、`token` 或 `password`；原 scope 只用于说明旧归属。每个 owner 下的导出项 ID 应稳定且唯一；改变凭据来源身份时使用新的项 ID。sourceRef 由原归属和项 ID 得出，不由 secret 派生。

## 实现

Electron 原生文件选择器限制为 JSON。主进程在内存中解析和暂存值，10 分钟过期、最多 16 个待处理文件；UI 只得到来源文件名、原归属和无值预览。Host 要求某一项的值时，App IPC 校验 pending ID、credential ID 和 sourceRef，回复错误使用固定码白名单。值在成功确认前可由同一 Host 命令重读，以便恢复未知回执；成功、取消或用户清除预览后即清理。UI IPC 仅在 App 提供；Super-agent Host 拒绝远程 client 的导入管理调用。

用户逐项填写新资源名、role、purpose 及 work item、Environment 或 source Instance。导入前验证 `tool` grant 至少绑定 work item 或 Environment，`source`/`outbound` 至少绑定精确 source Instance；不接受 role-wide imported grants。旧 grant 不复制。Host 先固定 target 到 `product-credential-import`，再向受信 App 请求值，调用现有 `ProductCredentialManager.create` 与 `grant`；sourceRef 和导入 attempt 派生稳定命令 ID，重复 commandId 的异文会被拒绝。业务记录只存原归属、target、attempt、状态、resource ID 和 grant ID，不存 secret 或 pending ID。成功后 App 移除该项暂存值。

状态包括 `pending`、`importing`、`unknown`、`applied`、`conflict`、`cancelled`。同一 sourceRef 不允许改 target。Host 启动恢复若已撤销并封禁一个没有业务回执的 vault 创建尝试，下一次用户重试递增 attempt 并派生新的稳定命令 ID；仍 pending 或已有业务回执的尝试沿用原 ID。凭据 Manager 在 Engine 内复用，周期性恢复扫描因此能识别同进程中的在途创建。取消先持久化墓碑，再等待本进程中的导入动作结束；已创建资源通过 Manager 删除，vault 清理失败时可重试。Host 交接后遇到迟到 vault 写入，由既有 bounded `resumeCreations` 扫描继续撤销。数据库和 DSH credential provider 不声称跨存储原子提交或 exactly-once。

现有凭据资源设置页新增受控导入入口，显示来源文件、原归属、原 scope、新 target 和导入状态。每项默认没有授权目标；用户必须显式选择 role 和 purpose。冲突、未知、取消及 vault 清理待办均显示可恢复状态；DSH vault 不可安全浏览的说明同时指向手动创建资源。
