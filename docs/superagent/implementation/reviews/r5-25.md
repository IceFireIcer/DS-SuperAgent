## Standards

模块只从调用方给出的对象抽取白名单数据；无 DSH 安装或用户旧资料访问，不修改旧核心/UI 文件。新建与应用都经过现有 `validateRoleConfig`；最终写入仍要求受信 Engine 命令及 revision CAS。测试入口在模块未注册公共包入口时单独编译模块；这是本轮避免共享文件冲突的有意边界，产品包导出尚待接入。

检查中修正了 TypeScript 对未知对象的收窄、无效旧图片导致有效颜色/形状一起丢失，以及起初过小的头像容量。剩余风险：图片仅校验内嵌 data URL、类型特征与大小，未解码像素；实际 UI 仍须安全渲染并完成独立形象资源契约。调用方必须提供明确取得的 JSON 副本，不可把实时旧状态直接交给此接口。
