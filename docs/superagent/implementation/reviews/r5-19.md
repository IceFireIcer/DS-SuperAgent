## Spec

持久 control 事实绑定资源与工作代次。Worker 访问在持久 `taking` 提交时即阻断，Host hold 失败/超时不会自动释放；相同 control ID 可重连确认。显式归还保留 stop、Attention 与未解决 operation；operation 未核查时拒绝归还。受权 UI 可在现有隔离 profile WebContentsView 中手动导航，服务端 HTTP(S) 校验沿用 App 现有导航策略，远端只读客户端不能取得 control view。停止工作调用现有 work-stop 命令。新增测试覆盖持久恢复与命令状态；App BotViews IPC 的归还后防旧 renderer 操作测试在补齐本地依赖后 23/23 通过。真实 Electron/CDP、多进程与 Postgres 不是本轮通过证据。独立 Spec 子代理错误地读取了其他仓库的同号 issue；已按本仓库实时 GitHub issue #111 与发布映射复核，不采用其错误标题结论。
