## Standards

复审确认当前 Router attempt 先持久 pending，再记录 completed/failed 的精确序列、step 数和预算；失败 turn 不会丢掉审计。超长工具与 report detail 使用有界分页和 opaque 引用，读取时重新校验 observation、Instance、Ticket、Assignment/report，并拒绝猜测；`historyStatus` 不再把缺失 Session 当空历史。生成 `client.js` 一致性、Super-agent typecheck 与 UI 边界检查通过。

复审留下的非阻断风险已处理两项：待定 Session 现在通过 `not-started` 真正可达；新增 detail 控件有显式键盘焦点环，并补齐新增事实标签翻译。report detail 仍按 assignment/report 身份而不是每次 generation 参数重复证明，但其 locator 只能在对应 Ticket 的 report history 中解析，不能跨 Ticket；进程在 pending Router turn 写入后崩溃时，该 attempt 保持 pending，直到原有界效果重试或人工处理，本票不新增启动时自动改写历史。
