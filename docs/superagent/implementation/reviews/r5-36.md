## Standards

两轴静态复核发现的阻断已处理：启动失败时安装更新使用已退出 Host 的离线备份路径；备份确认公开 profile 所用 Session provider；桌面还原失败支持锁内回滚；异步安装器错误会记录并重启 Host；不可恢复快照不能放行安装。备份目标解析后继续拒绝和个人 DSH 路径重叠。恢复确认使用危险操作样式；用量索引读取归属 `RoleConfigStore`。

初审由两位代理并行完成。最终独立复审因 DNS 故障中断，由实施者逐项复核接线与验证结果。其中退出监听修正为 Electron 原生 `autoUpdater` 事件，桌面测试覆盖了安装失败后撤销退出并重启 Host。设置沿用现有 DS SuperAgent UI 和 DSH 公开 API，纯管理入口不派生 Main 命令或 Ticket。

## Spec

R5-36 的升级、观测、分开备份/恢复、失败修复和证据分层已接入。安装前须完成独立 SQLite 与 JSONL Session 快照，且该快照必须通过可恢复性检查；未知外部副作用、未解决工作、变动授权或不支持格式会阻断安装或恢复。待启动的数据通过恢复日志回滚；已启动数据先标记提交，随后才清理旧副本。隔离 DSH profile smoke 验证了历史、人工 stop、角色设置与日程授权的保留。
