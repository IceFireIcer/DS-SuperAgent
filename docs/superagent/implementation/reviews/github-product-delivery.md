# GitHub 产品外发复核

基线 `1a04119d`。两位代理分别复核标准与 #129 的验收要求。 [实施记录](../github-product-delivery.md)

## Standards

- 账号检查和实际发帖现在共用同一凭据。每次 API 调用在消费前复查凭据，最终事务同查来源选择与授权。文档已更新到受管凭据设置路径。
- 只返回经确认的评论 ID 和 URL。源码、回执与测试报告不保存真实凭据或讨论正文。测试通过产品公开接口核对授权和回执。

## Spec

- 修复了回复更新父讨论时间后可能使工作结果失效的情况。已知的真实内容变化仍按原来源版本规则处理。
- 缺少配置时仍使用明确的产品外发判断。撤权或轮换发生在提交前时拒绝写入，原外发结果未知时使用原讨论、身份和标记核对。
- 受控用例在授权验完后轮换或撤权，两个外部提交均未发生。对账用例覆盖发帖响应丢失和来源原评论删除。测试仓库的真实结果回执另有证据。
