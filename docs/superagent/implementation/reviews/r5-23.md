## Standards

依照 `AGENTS.md`、`CONTRIBUTING.md` 与 `docs/design/ui-standard.md`：不修改 DSH/用户数据或旧 Bot 调度；仅改产品入口与现有 DS Bot 客户端组件，英文源文案及中文翻译随源码生成 `client.js`。工作树与主检出隔离，UI 边界使用用户明确请求的授权标志通过。新持久记录在 `recordKinds` 共用表中，未新增 SQLite 专属字段。读端按 Instance/客户端能力核验，只有本地设置能改规则；远端只读客户端停止被网关拒绝。

自检发现并修正：历史准备记录没有隔离目录字段，预算计数不能丢掉这些记录；轮询主对话不能每次扫描全部运行历史，改用十条有界通知索引；产品规则限定来源实例、Feishu app 发送者和简单字面匹配，避免来源内容触发昂贵的任意正则表达式；生成词典的重复键已去除。没有引入与本票无关的 UI 重设计。

## Spec

已验证 observe 不执行、auto 在规则命中与次数/步数/时限/文件预算内生成可读审阅材料；来源不能授予发信、PR 或合并工具；规则变更、暂停和精确人工 stop 使迟到结果失效。产品 Host、Engine、Feishu 接收器、本地设置、主对话摘要与受授权远端查询形成一条 mock 闭环；主对话只显示有用结果。

未完成：GitHub/CI 的三层产品来源尚未接入此规则页面；准备运行有持久索引但不是正式 Router Ticket/Mandate/Assignment，不能代替有授权的原工作；没有受权仓库快照/测试复现和真实 token/金额账本。保留 #115 开放，不将来源正文或 CI 事件当成发布授权。真实模型质量和 Feishu 租户端到端仍未验收。
