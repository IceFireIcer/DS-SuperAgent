## Standards

首轮发现 `followUp()` 过长、集成测试 responder 混杂、回调请求形状重复，以及干净提交误带入两项无关 PostgreSQL 测试。修复把验证、目标解析、指纹和记录投影拆成小方法，提取测试 responder，共享 `MainFollowUpAttachmentRequest`，并把 PostgreSQL 范围恢复到仅验证本票跟进与重启。复审剩余 0。

## Spec

首轮发现两项必须修正：`claimedAt` 是发送前 claim，不能作为 Worker 已采用；Main Session 换代不应因 WorkBrief 的旧 Session ID 被拒绝。现在 `adopted` 只来自 completedAt 的 ready/Attention/handback，claim 与已持久投递分别显示；FollowUp 校验并记录当前 Main Session，同时保持逻辑 Main 身份。来源恢复仍严格要求 Mandate scope 与 Trigger 一致，只对经 `work-ticket → work-item → WorkBrief` 验证的 R5-03 分项放行 item scope。

复审确认精确 workItemId、A/B 隔离、同 Ticket/Session、直接路由记录、停止/等待/结束恢复、handback 与 Main 有界更新均覆盖，没有新增自动派活或页面猜目标。复审剩余 0。
