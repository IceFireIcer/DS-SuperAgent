# R5-24 双轴自检

- 工单：[#116](https://github.com/IceFireIcer/DS-SuperAgent/issues/116)；基线 `cfcc189`。
- 范围：独立运维进程、产品健康事实、语义 Session、受信审批、设置页与持久历史。

## Standards

使用已有 Watchdog/Supervisor/Engine 命令及 `RecordKind`；新的 `supervisor-run` 在 SQLite 和 PostgreSQL 上共用同一注册与事务形状，PostgreSQL 独立连接读回合约通过。客户端沿用现有设置组件、主题色和本地化，构建生成 `client.js`，未编辑 DSH、旧 UI renderer、用户数据、`CHANGELOG.md` 或 `.idea/`。为防止 worktree 复用依赖目录时将主检出绝对路径写进生成物，构建脚本显式保留符号链接；`office.js` 保持无差异。受信产品 Host 拒绝远端客户端的审批/历史调用；读取提案按当前 Main work card 归属过滤。

## Spec

独立 CLI 复用现有一小时默认巡检、预算、去重和优雅恢复；Main 失败、Router/Worker 错误、来源/setup 和正常等待分类不共享重启决策。语义监督沿原 Engine 公开事实查证，只产生提案，人工批准前不执行；本地每小时 24 次检查预算独立于提案预算，持久计数不受显示历史截断影响。批准时重验当前方向、代次和 stop，纠偏事务内再次阻挡人工 stop，旧版本和外来源提案不能从受信设置页获批。未知结果沿原身份对账，普通等待不按时间误判。局部失败及巡检不足范围留在历史或状态中可查。

限制如实记录：默认桌面 shell 启动的 Host 并非 CLI 子进程，`ProcessWatchdogHost` 会拒绝对该活进程执行自动替换；生产 Watchdog 常驻服务配方、真实服务器/Windows 接管证据仍归 T58。SQLite 异常退出留下的单机锁需操作者核实和清理。语义巡检最多处理前 100 Ticket，超过时标记 partial；真实模型质量与飞书 tenant 未测。因此本地实现不等于 #116 所有部署形态的最终验收，也不关闭工单。

## 证据

Node 24.22.1 定向 Super-agent 相关回归 55/55、加入产品组合和局部故障分类后的相关组复验 40/40、最终预算与路由窄测 9/9、隔离 PostgreSQL 合约 1/1；Super-agent 构建、typecheck、lint，DS Bot 生成一致性、完整 lint（仅既有 warning）、真实 React 设置/预设交互及翻译/状态合并 13/13、基于固定 `cfcc189` 的 UI 边界和差异检查通过。没有全量 CI、真实模型、真实 Feishu、实际桌面窗口或服务器替换验收。

合并当前 `dev` 的 R5-23 规则/设置后，额外定向复核产品 Watchdog/Supervisor/主动规则/飞书 Host 27/27、客户端监督/主动规则/预设 8/8；生成一致性、类型检查、lint、实施记录和 UI 边界通过。独立 Watchdog 仍仅能安全替换自己启动并持有 IPC 的 Host，不能据此声明默认桌面 shell 或真实服务器的替换验收。
