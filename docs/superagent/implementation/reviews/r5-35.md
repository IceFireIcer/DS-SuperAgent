# R5-35 复核

复核基线 `9854700b`，[#127](https://github.com/IceFireIcer/DS-SuperAgent/issues/127)。

## Standards

独立审查发现固定 DSH 路径的保护范围、测试环境变量继承和手工工作流并发组问题。最终实现同时检查个人 DSH 默认路径与配置路径。打包 smoke 使用显式临时工作区和 profile，桌面包工作流有自己的并发组。前端复用 Main 与设置组件，英文和中文文案一起生成。

## Spec

独立审查指出共享安装身份会接管旧产品，旧环境变量可能打开旧状态，失联目录会被重建，缺模型在首次发送前不可见。最终使用新 NSIS GUID 和 deb 身份，删除旧启动变量和发布别名。目录失联回到原有位置设置，缺角色模型在 Main 和设置中可见。平台证据见[实施记录](../r5-35.md)。
