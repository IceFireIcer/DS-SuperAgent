# R5-14 增量双轴复核

- 工单：[R5-14 / #106](https://github.com/IceFireIcer/DS-SuperAgent/issues/106)。
- 范围：[实施记录](../r5-14.md)所述本地产品输入、输出和语音接缝；#106 保持开放。

## Standards

按仓库公开 DSH API 使用附件准入、文件/图像内容块及语音 Remote；没有修改 DSH。首轮发现产品上传 8 MiB 与 Environment 原 64 KiB 存储上限冲突、脱敏证据页无法原样下载、录音初始化期间卸载可能留下设备流、工作目录切换令已上传资源失配，以及新增按钮焦点样式缺失。已分别扩展只供产品使用的有界存储路径、隔离原字节下载与 Worker 脱敏页、加入录音代次检查、固定附件目录与新增焦点规则。服务端拒绝远端客户端文件端点；UI 不把未接通的远端文件能力伪装为可用。新 profile 纳入原语音 bundle，只有服务实际就绪时使用公开 Remote，否则复用已有浏览器听写。本次增量未变更 DSH、Host 或客户端，复用现有业务记录种类以保持 SQLite/PostgreSQL 存储形状一致；Node 24 定向检查通过，PostgreSQL fixture 与全量 CI 未运行。

## Spec

本地消息保留文本和已准入非文本块；资源在 Instance/来源/Environment 下存引用，Worker 能读原文件并生成可归属下载的产物，获授权图片也保留在其原生 Session。首轮发现多工作项共享所有附件引用，因此暂拒绝多项委托。本次增量通过原上传 ID 把附件目录绑定到每个 workItem；Router 无法扩大 Main 的分配，两个明确分配的 Ticket 各自成功，单条人类输入与来源身份不复制。Worker、子代理的 `read_asset` 逐 Ticket 验证 grant；同摘要文件负对照先复现越权读取，再由服务端拒绝，拒绝码在工作观察工具事实中可查。两个原生图片引用分别仅进入各自 Worker Session。服务端按工作 ID 查产物，避免仅从最近 20 个工作卡查找。读文件通过分页原字节通道，业务证据仍按原有规则脱敏；上传回执丢失与排队输入撤权各有定向回归。外部来源附件、执行中撤权、真实图像模型与原生窗口交互未验证，不将本次定向测试扩大为整个 #106 的验收。

## 2026-11-16 独立分支：飞书平台二进制增量

### Standards

相对 `c55eb01` 核对 `AGENTS.md`、`CONTRIBUTING.md` 与实施文档：只改 Super-agent 的飞书来源 API/runtime、附件准入的受信 Environment Actor、产品 Host 的受信装配、定向测试和本票记录；没有改 DSH、UI、`client.js`、MCP 工具或 supervisor/proactive 逻辑。接收 Actor 与本地存储 Actor 各自保留，不让飞书来源 Engine 持有工作目录命令接口。密钥只由既有受信凭据回调交给 API 请求；错误、Main 投影及日志不带原始平台键、字节、Host 路径或密钥。Node 24 的 typecheck、Super-agent lint、构建和 UI boundary 检查均通过；没有运行全量 CI。

### Spec

平台 `file/image` 的资源键先与当前原生消息 ID、聊天、发送者、版本及消息正文核对，再在同一受信来源权限下获取有界字节，下载后复核，最后走既有 DSH 附件准入和来源事务。产品 Host/Main 定向场景核对两个原生内容块、Instance 与默认 Environment、去重重连和不暴露原始资源键；平台错误、资源缺失、消息撤回、假借消息、尺寸超限和缺少资源键均拒绝。既有多工作项授权、跨项同摘要拒绝及读/下载撤权场景作为回归，不将其重算为本次新增能力。Node 24 定向 26/26、typecheck、lint、构建、UI boundary 和差异格式检查通过。没有真实飞书租户/设备、GitHub 原生文件授权、PostgreSQL 专项或远端文件传输证据；音频/媒体/富文本资源先拒绝。#106 维持 OPEN。

## 2026-11-17 可用性复核

### Standards

沿用同一 Environment 的已有受信产品附件接口、DSH 原生内容块和工作卡，不新增 renderer 或修改 DSH。产品专用读取只在已鉴权的附件/产物入口使用；Worker 工具仍使用原有脱敏/大小限制。远端只用既有加密设备协议与原生上限，不提升设备权限或向远程只读客户端开放文件接口。新增设备侧保真/脱敏对照测试和产品 Host 产物归属测试。

### Spec

本地上传大于 64 KiB 时现有入口原来不可用，现已由定向测试覆盖；授权原文产物、远端自动选择后的同世界产物均可按工作卡读取。原文下载按工作项和 Environment 限定；历史 Session/Worker 事实不回溯改写。主对话语音输入继续复用已存在的公开语音服务/浏览器听写，转写进入原草稿并由原发送命令提交。GitHub 正文 URL、真实飞书租户、真实模型与跨平台组合仍按来源/环境分别验收。最终全量本地测试及双轴审查结果需在提交前补充。
