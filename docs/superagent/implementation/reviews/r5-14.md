# R5-14 增量双轴复核

- 工单：[R5-14 / #106](https://github.com/IceFireIcer/DS-SuperAgent/issues/106)。
- 范围：[实施记录](../r5-14.md)所述本地产品输入、输出和语音接缝；#106 保持开放。

## Standards

按仓库公开 DSH API 使用附件准入、文件/图像内容块及语音 Remote；没有修改 DSH。首轮发现产品上传 8 MiB 与 Environment 原 64 KiB 存储上限冲突、脱敏证据页无法原样下载、录音初始化期间卸载可能留下设备流、工作目录切换令已上传资源失配，以及新增按钮焦点样式缺失。已分别扩展只供产品使用的有界存储路径、隔离原字节下载与 Worker 脱敏页、加入录音代次检查、固定附件目录与新增焦点规则。服务端拒绝远端客户端文件端点；UI 不把未接通的远端文件能力伪装为可用。新 profile 纳入原语音 bundle，只有服务实际就绪时使用公开 Remote，否则复用已有浏览器听写。

## Spec

本地消息保留文本和已准入非文本块；资源在 Instance/来源/Environment 下存引用，Worker 能读原文件并生成可归属下载的产物，获授权图片也保留在其原生 Session。首轮发现多工作项共享所有附件引用；已改为 WorkBrief 单独记录资源并在有附件时拒绝多工作项委托。服务端按工作 ID 查产物，避免仅从最近 20 个工作卡查找。读文件通过分页原字节通道，业务证据仍按原有规则脱敏；上传回执丢失与排队输入撤权各有定向回归。仍需逐项资源授权后才能支持复合多工作项；外部来源附件、执行中撤权、真实图像模型与原生窗口交互未验证，不将本次定向测试扩大为整个 #106 的验收。
