# R5-13 双轴审查

- 基线：`e24ac8e`（R5-05 记录完成）。
- 范围：三层结构化事实、Outbox 用途/依据/目标复核、跨受众约束、交付状态和原幂等键对账。
- Spec：GitHub #103、`docs/superagent/spec.md` D02/D03/D05/D12；A16/A17/A18。

## Standards

本地自检确认用途校验仍集中在既有 Outbox，未新增外发旁路；unknown 状态来自原 Effect receipt，公开对账命令绑定 Delivery、Ticket、Effect generation 和原 idempotency key。临时失败仍走既有有界退避，命令重放没有追加发送。定向 lint、typecheck 和相关 36 项回归通过。

## Spec

acknowledgement、answer、attention、result 的现有依据检查继续覆盖当前请求、问题、Worker fact、ready report 与精确目标。新增 `unknown` 和 `reconcileRequired` 不再把平台丢响应伪装成 pending；跨受众仍要求 current evidence、owner 授权和现有 association。复审剩余阻断项为 0。

当前工具环境没有提供 `code-review` 技能要求的并行子代理 namespace；本记录明确为本地两轴自检，不冒充独立子代理结论。
