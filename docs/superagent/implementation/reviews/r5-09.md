## Standards

- 检查 `AGENTS.md`、`CONTRIBUTING.md`、R5 总规格、现有 NativeSessions/ContextReader/Product Host/UI 边界。

- 本阶段剩余阻断项：0。

## Spec

- `max-tokens` 将 Main 切换到已持久化的 forked child；`mainId` 不变，generation 前进，旧 Session 和业务消息历史继续可读。
- rollover 记录工作索引、目标、约束、验收、状态和 Ticket/report/attention evidence refs；queued input 在 context-full 回合中单独测试并进入 unread handoff。
- stop 状态在 rollover 前写入 Ticket，交接后工作索引仍为 stopped。waiting/unknown 使用同一持久工作投影进入 workIndex，不会被 rollover 清除；直接的停止/回答 UI 仍归 R5-06/R5-07。
- Main 工具与 Engine 都只能读取已接受工作的精确证据；测试实际从 Main 调用工具，并用 256 字节页续读原请求；伪造 `ticketId` 返回 `INVALID_INPUT`。
- 部分证据显式返回 `truncated`、字节总数、返回字节数和 cursor；现有 Main UI 提供原始请求分段加载，不以摘要伪装全文。
- 旧 Session 延迟完成场景在业务 generation 推进后返回 `MAIN_TURN_STALE`，当前历史不接受旧回复。
- 审查当时本阶段剩余阻断项：0；完整 #101 仍待 R5-06/R5-07 与真实模型/组合环境汇合验收，当前证据为确定性 mock 和真实公开 profile 接缝。
