## Standards

使用产品 Engine、公开 DSH Worker tool scope 与既有 Host/CDP 端点；未修改 DSH、旧 DS Bot UI、生成资产、用户 DSH 数据、`.idea/` 或 `CHANGELOG.md`。浏览器操作通过受信 Instance 存储事务与现有 Host lease fencing 写入，SQLite/PostgreSQL 共享 record kind 白名单。失败只返回固定错误码，业务投影不含 Cookie、页面正文或 URL。测试使用虚构资源和隔离临时库。新增浏览器专属模块承担资源、租约和操作身份；共享 Engine/Execution/Host 只接入窄范围调用。未发现新增的标准违规；Playwright 依赖固定到仓库浏览器后端使用的版本。增量没有前端代码，因此不生成客户端资产。

## Spec

已覆盖 #110 的局部资源/Environment、不同资源存储分区、精确 Worker 工作授权、同资源租约冲突、操作身份与停止/失权/未知结果事实。跨 Instance、未授权工作、Main/Router、远端客户端与另一个运行中的 Worker 均不得借用资源。停止若有未决浏览器操作不确认取消；人工按原操作 ID 核查后才能继续。当前新产品只实现导航与只读正文快照，未声明写控制、旧登录态导入或跨库 exactly-once。

仍不满足完整验收：旧 DS Bot 浏览器面板尚未映射新资源、展示状态及接管/对账入口；#107 动态凭据和可选旧资源导入尚未齐备，未有真实 Electron/CDP/多进程/PostgreSQL 证据。由此 #110 保持 OPEN。手工检查点是产品面板是否使用资源身份而非 Bot ID，并在真实 Host 断线、人工接管和外部动作回执丢失时保留同一操作事实；这些不能由本轮 mock 测试替代。

## 2026-11-17 产品面板复核

**Standards**：新页面挂在现有 Super-agent 设置入口，只复用 `Card`/`Row`、DS Bot 样式与公开 Host 命令，没有恢复旧 Bot 设置或另建 renderer。资源投影按 resource 前缀读取最多 100 条 workItem/active grant并标记截断，其他资源的 101 条历史 grant 不会拖死当前资源；Worker 的 `browser_resources` 投影没有增加授权明细。组件按动作使用稳定 command ID、revision 和原 operation ID 提交，未知回执只阻塞同一动作；UI 不含 profile key、Cookie、页面正文或 URL。生成客户端、i18n、样式归属、lint 与 UI boundary 通过。

**Spec**：本地设置页现在使用资源/Environment/workItem 身份创建和授权浏览器，显示 available/busy/unknown/revoked、owner、revision 和最近操作；状态自动及手动刷新，未知命令只阻塞对应 action/operation。unknown/被放弃操作必须选择固定核查代码，不接受可夹带 URL、表单值或页面正文的自由文本；`NOT_FOUND` 会清除失效命令，无 accepted work item 时仍可撤销整资源。远端客户端仍不能读取或管理浏览器资源。R5-18 四项代码行为已完成，后续人工接管/归还及写操作属于 R5-19，不把本票 mock 当作真实 CDP 验收。
