## 交付行为

现有 `ds-bot` 产品 UI 增加 Host 连接入口。桌面主进程通过同一个 `ClientAccess` / `createClientGateway` 接缝请求远端产品投影；前端继续使用 Main 对话、工作卡和只读 Router/Worker 观察组件。窗口重载与重新输入同一凭据读取原 Main binding、历史与观察快照，不启动远端新 Main 或新工作；断开桌面客户端不会关闭远端 Host。客户端凭据只保存在桌面进程内存中，退出后要重新输入。

网关的产品模式只开放 Main 历史、授权观察、有限证据/交付查询和明确的 Main/工作控制命令；通用 Ticket、Session、旧命令路由及客户端管理操作在产品模式下不可访问。每次读取与命令都重新验证同一 Instance 的 `read`/`command` grant，撤销后下一次请求被拒绝。远端命令 ID 按已认证客户端隔离，Main 输入保留客户端来源身份；产品快照先取游标，再读 Main 和观察事实，持久事件窗口按稳定键去重并可从游标补读。只读凭据在 UI 中也没有写入口，但拒绝以服务端权限为准。

合并 R5-17 与飞书来源后，Main 消息同时保留客户端、GitHub 和飞书来源；发送指纹仍包含用户选择的目录。目录选择/注册及飞书来源启停留在 Host 的本地受信 UI；远端客户端用 Host 已配置的默认目录工作，不取得文件浏览或来源管理权限。

本地产品设置可在运行中的 Host 上签发一次性凭据、列出不含密钥的客户端记录和在线撤销。远端网关不暴露签发、撤销或角色设置路由。凭据只显示一次，用户可从设置复制到桌面连接表单；不写入仓库、产品投影或日志。

## 传输与操作

产品 profile 仅在设置 `DS_SUPERAGENT_CLIENT_PORT` 时启动专用网关；`DS_SUPERAGENT_CLIENT_HOST` 默认 `127.0.0.1`。非回环绑定必须同时设置 `DS_SUPERAGENT_CLIENT_TLS_KEY_PATH` 和 `DS_SUPERAGENT_CLIENT_TLS_CERT_PATH`，并由客户端验证服务器证书。回环 HTTP 只能用于本机连接或由操作者另行建立的授权 SSH 本地端口转发；客户端拒绝普通远程 HTTP、URL 中的用户名/密码及跨站跳转。桌面应用本地 Host 只负责承载现有 UI，远端授权 Host 的工作生命周期独立。
