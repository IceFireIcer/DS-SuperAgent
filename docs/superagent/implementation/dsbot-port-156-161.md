# DS-Bot 迁移：手机、浏览器、电脑操控与设置

范围：[迁移规格 #142](https://github.com/IceFireIcer/DS-SuperAgent/issues/142)，切片 #156–#161。复用 DS-Bot 0.3.8 (`5e9b7da8882da3b68d8a0624342708c2150a9156`) 的能力代码和组件。产品沿用现有设置壳和 `/api/product`，不加载旧 Bot、群聊或存储。

## 产品路径

- #156 手机：在设置保存中继地址并开启。一次性二维码默认只读，可由本机用户对本次配对勾选发送权限。Noise 固定对端身份，中继不解密消息。Host 通过 Main 的持久输入队列处理手机发送；手机不能上传本机文件引用或调用本机设置。撤销断开当前连接并阻止重新配对之外的重连。
- #157 浏览器：链接引用、步骤脚本、任务计划共享当前 BrowserView 和资源授权。每步复核工作、租约、插件版本和接管状态，结果不明时须先核对。脚本和任务使用有界步骤，不运行任意 JavaScript；提交表单、支付和其他敏感操作由本机用户接管。
- #158 电脑操控：本机开启并选应用和级别，当前本机 Worker 申请短租约。本机确认通过且悬浮提示成功显示后，驱动才可查看批准的窗口、截图、执行点击或请求前台操作。无驱动、无系统权限或撤权时不执行；截图只在本机设置预览，任务结束、接管或停止收回控制。
- #159 定时任务：日程和定时任务各自列表、取消及来源开关，复用同一有界调度器。定时任务到期进入 Main；暂停前已生成但尚未被 Main 接受的移交作废，不会在重新开启后补发，原因保留在运行历史中。
- #160 用量：从原生 Session 已报告的用量事件按小时、角色、模型和种类聚合，热力图按 UTC 日显示。用量和状态互换不清空筛选或确认状态。状态保留更新、备份恢复和诊断。
- #161 密钥：从 Main 或设置审批当前本机 Worker 的凭据申请。批准时复查执行代次与环境，向原工作送达一条不含值的续办通知。轮换、删除和撤权继续使用现有凭据库。密钥只由受信配置使用，不注入任意 shell。

## 运行手机中继

安装产品 npm 包后执行 `ds-superagent-link`（从源码构建后可运行 `node superagent/dist/phone-relay-cli.js`）。默认监听 `127.0.0.1:8787`，WebSocket 路径为 `/v1/link`。跨设备部署时，应在中继前配置可信的 TLS 反向代理，并在手机设置填对应的 `wss://` 地址。`DS_SUPERAGENT_LINK_DATA` 可指定中继的设备登记文件；它不存储聊天内容。新版手机 App 不属于本批，旧 DS-Bot 配对码不通用。

## 审查与验证

- Standards：手机发送在写入 Main 的事务内再次校验配对和权限。电脑输入先留无内容的持久记录，未经本机核对不得重做未知操作；Worker 不读取窗口原文或截图。已补 npm 包的上游许可和热力图的键盘日期查询。
- Spec：运行时只引用受 Git 跟踪的组件；密钥批准与续办同事务。活动筛选与全部纳入 Session 的总量明确分开；任务暂停语义沿用已有日程，不补发失去授权的移交。
- Node 24：类型检查、构建、lint、生成 bundle 检查、UI 边界检查通过。25 项服务端与 27 项客户端定向测试通过，覆盖回环加密配对、Main 接收、撤销重连、Browser lease 与接管、电脑权限与未知结果、日程隔离、原生 Session 用量和密钥审批续办。
- Windows 桌面包测试 252 项通过、1 项跳过；已读取原生 CUA 驱动能力清单。Windows x64 解包产物检查确认包含手机中继、客户端、桌面桥、CUA DLL 和 Node 原生运行库。没有启动该解包产物或发布安装包。
- 本批没有手动发起全量 CI、真实手机或公网中继部署，没有操作用户的实际桌面应用，也不把夹具结果当作 macOS/Linux 真机验收。
