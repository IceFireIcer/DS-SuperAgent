## 用户可见行为

产品设置原有凭据资源卡可创建资源并为 Worker 的 work item 或 Environment 授予 `tool` 用途。新增 MCP 卡显示受信 Host 声明的服务/工具、Host 本地运行位置、所选资源、审批与连接状态；可保存资源、审批/撤销审批、连接、断开、重试。配置动作只写 Instance 内的配置与命令回执，不创建 Ticket。首次声明的固定工具默认未经批准且断开；保存新选择同样清除审批及连接，需重新批准并具备 Worker/tool 授权。

Engine 的受信配置工厂把配置记录存入与其他业务事实同一 Storage 合约。每个配置命令带稳定 `commandId`、规范化指纹和 revision 条件；跨 Instance、只读/远端客户端、陈旧 Host 租约和不同输入复用同一命令均在服务端拒绝。设置页只在结果不明确时保留原命令 ID 重试，确定性拒绝允许修正。凭据值与 MCP URL 不进入设置投影。

断开、审批撤销、资源撤权/删除及部署声明变化均在实际 Worker 调用前重新读取；现有 MCP 适配器在握手后、发出 `tools/call` 前再次检查 Assignment 与受管资源。调用时检查精确 Worker/work item/Environment grant，Main/Router 和远端 Assignment 不取得此工具。`connect`/`retry` 是有持久回执的本地启用与授权核验，MCP 网络握手发生在真实工作调用时，界面没有宣称网络已连接。已确认调用继续由现有 ReadyReport 记录工具事实。
