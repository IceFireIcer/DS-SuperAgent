# 桌面候选包验收（#182）

桌面包探针从 Git 读取候选提交中的客户端，核对包内客户端 SHA-256，并记录应用版本、平台、架构和构件指纹。Main 收发在隔离 Profile 和 mock 模型中进行，提交前等待默认目录指向获准的本机夹具，并确认界面显示该环境可用。

Windows 安装版从本地更新源下载下一版。探针等当前进程自然退出，再检查当前用户安装登记、安装进程退出和新版 `app.asar` 指纹。重新打开应用时复用原隔离 Profile，核对 Main、消息内容、定时任务设置、用量和可还原备份。应用主动退出时安装更新并保持关闭，用户选择立即重启时由安装器重开应用。

Windows 视觉探针覆盖 580 和 1120 像素视口、四套主题及浅深模式。目录菜单和账户菜单抽验焦点环、布局边界、方向键、逐层 `Esc` 与外部点击。深色组合同时模拟系统减少动态效果。工作控制探针分别检查原 Assignment 的问答、停止 Main 回复和停止选定 Ticket。

## 本地验证

- `3c270ed0` 的客户端入包后，Windows x64 `0.2.5` 解包构件通过 `--coexistence`、16 组视觉探针及 `--controls`，均自然退出，退出码为 0。构件 `app.asar` 的 SHA-256 为 `b17b569f8a52c29e4f6e698662ac3361dd3cf0b35aaa5885b794aa0c66cb8296`。
- Node `24.22.3` 下，桌面测试 255 项通过、1 项跳过，进程正常退出。

## 远端验收

本机记录覆盖解包构件。Windows 安装与覆盖更新、macOS arm64/x64、Linux AppImage/deb 和服务端全量测试以同一候选提交的远端工作流结果为准。真实模型及外部接入的验证暂缓。
