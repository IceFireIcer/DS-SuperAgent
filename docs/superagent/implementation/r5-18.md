## 已实现的局部行为

受信产品 Host 可以按 Instance 和本地 Environment 注册浏览器资源，并对精确 workItem 授予或撤回使用权。创建、授权、撤权和人工对账使用稳定命令 ID 与资源 revision；相同输入重放返回原回执，异文复用拒绝。业务库只保存资源元数据、授权、租约和操作身份，不保存 Cookie 或页面正文。资源的 Host profile key 从产品 Instance 与资源 ID 派生，符合现有桌面 Host/CDP bridge 的身份形状；不同资源与 Instance 使用不同 Electron 存储分区。旧 Bot 的 botId、profile 和登录态不自动导入或共享。

本地 Worker 及其继承同一 Assignment 的子代理能看到 `browser_resources` 和 `browser_use` 工具名；没有精确工作授权时前者返回空列表，后者在 Host 拒绝实际调用。Main、Router 和远端 Assignment 不获得这些工具。每次使用核对当前 Host 租约、产品工作项、Ticket、Assignment ID/代次、LocalEnvironment、grant 与停止约束；Worker 只能看自己的授权资源及占用状态，看不到其他工作的身份和操作史。受信本地 Host 的 `browser-read` 才能读取有界的原操作记录，远端客户端不能管理资源。

同一资源的租约覆盖整个有效 Assignment，而非单个模型调用。另一个正在运行的 Assignment 会收到 `BROWSER_BUSY`，不能暗中共享控制。操作意图在向 Host 发送请求前持久化，操作记录包含原始 ID、Ticket、workItem、Assignment 和代次；已确认回执才写成功。停止、撤权、超时、回执丢失或 Host 切换使结果不明时保留 `pending/unknown`，同一资源在人工按原操作 ID 记录页面核查前不可再用；Ticket 停止、重试、恢复及 Host 接管沿用该未决屏障。人工对账只记录核查事实，不伪造浏览器动作已成功或跨进程 exactly-once。当前工具只支持打开 HTTP(S) 页面和有界正文快照，网页文本作为不可信数据进入本 Worker Session；工具事实与资源投影不保存 URL、Cookie 或页面正文。

实际桌面适配器经现有 `ds-bot:browser-endpoint` IPC 获取一次性 CDP 地址，再由 Playwright 连接现有 Electron Host 视图。它复用既有 Host 对导航、存储分区、权限与下载的约束，没有修改 `app/`、`ds-bot/src/client/`、`client.js` 或 DSH。没有桌面 Host IPC 的产品运行时不宣称浏览器可用；测试只注入虚构适配器。

## 2026-11-17 产品浏览器资源设置页

资源投影新增有界 `grants`，本地受权设置页可看出每个资源已有 work item 的 active 状态；Worker 使用的资源列表仍只返回资源 ID、Environment、名称和占用状态，不暴露其他工作的授权。整个 Instance 的 browser grant 索引超过 100 条时 fail closed，不能把截断投影冒充完整授权。

现有 Super-agent 设置页新增 **Browser resources** 页面，不恢复旧 `botId` 浏览器授权。页面使用 Host 的 `browser-list/create/grant/revoke/resolve` 命令：选择本地 Environment 创建隔离资源；按 accepted work item 授权或撤权；显示 `available/busy/unknown/revoked`、revision、当前 owner/ticket/generation 与最近操作；unknown 或被放弃的操作必须从“原页面未变、页面明显变化、页面关闭、已人工检查但不记录内容”选择固定核查代码后，才能按原 operation ID 核查。自由文本、URL、页面正文和表单值不接受。页面只在本地授权窗口出现，远端客户端仍无权管理资源。

每个动作按资源/操作使用稳定 command ID；创建或修改回执丢失时可在刷新/重载后按原 payload 重试，待确认命令只阻塞同一动作，不锁住其他资源。grant/revoke 使用当前 resource revision，`RESOURCE_STALE` 或已消失对象的 `NOT_FOUND` 会清除原命令并刷新；unknown 核查使用独立命令和固定代码。页面每 15 秒及手动刷新资源投影，资源投影、组件和操作历史都不包含 profile key、Cookie、URL、页面正文或凭据。

Node 24 定向验证：`browser-resources.test.mjs` 2/2、`product-browser.test.mjs` 1/1，覆盖同资源互斥租约、授权撤销、stale revision、跨资源 101 条 grant 不拖死其他资源、单资源 100 条展示上限、unknown 重启阻塞、固定核查代码及原 operation 核查；DS Bot `product-browser-settings.test.js` 1/1，覆盖同命令重试、动作级 pending 隔离、自动/手动刷新、工作 grant/revoke、unknown 核查、NOT_FOUND 解锁、无工作项时整资源撤销和无 CDP 桥不可用。`i18n.test.js`、`client-bundle.test.js`、`styles.test.js` 共 8/8，client 生成一致性、DS Bot lint、Super-agent build/typecheck、UI boundary 与 `git diff --check` 通过。未跑全量 CI、真实 Electron/CDP、登录站点或 PostgreSQL fixture。

据此，R5-18 的四项代码行为已完成，可按 `r5:code-done`、`fixed-in-dev` 关闭。人工接管/归还、点击输入上传下载等写操作继续由 R5-19 及后续能力票处理；真实 CDP、登录站点、真实模型、页面副作用与多进程竞争仍作为独立环境验收，不能由 mock 或设置页代码冒充。
