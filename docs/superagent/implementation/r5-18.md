## 已实现的局部行为

受信产品 Host 可以按 Instance 和本地 Environment 注册浏览器资源，并对精确 workItem 授予或撤回使用权。创建、授权、撤权和人工对账使用稳定命令 ID 与资源 revision；相同输入重放返回原回执，异文复用拒绝。业务库只保存资源元数据、授权、租约和操作身份，不保存 Cookie 或页面正文。资源的 Host profile key 从产品 Instance 与资源 ID 派生，符合现有桌面 Host/CDP bridge 的身份形状；不同资源与 Instance 使用不同 Electron 存储分区。旧 Bot 的 botId、profile 和登录态不自动导入或共享。

只有被当前工作项授予资源的本地 Worker 及其继承同一 Assignment 的子代理获得 `browser_resources` 和 `browser_use`。Main、Router、远端 Assignment 与未经授权的 Worker 没有浏览器工具。每次使用核对产品工作项、Ticket、当前 Assignment ID/代次、LocalEnvironment、grant 与停止约束；Worker 只能看自己的授权资源及占用状态，看不到其他工作的身份和操作史。受信本地 Host 的 `browser-read` 才能读取有界的原操作记录，远端客户端不能管理资源。

同一资源的租约覆盖整个有效 Assignment，而非单个模型调用。另一个正在运行的 Assignment 会收到 `BROWSER_BUSY`，不能暗中共享控制。操作意图在向 Host 发送请求前持久化，操作记录包含原始 ID、Ticket、workItem、Assignment 和代次；已确认回执才写成功。停止、撤权、超时、回执丢失或 Host 切换使结果不明时保留 `pending/unknown`，同一资源在人工按原操作 ID 记录页面核查前不可再用；Ticket 停止、重试、恢复及 Host 接管沿用该未决屏障。人工对账只记录核查事实，不伪造浏览器动作已成功或跨进程 exactly-once。当前工具只支持打开 HTTP(S) 页面和有界正文快照，网页文本作为不可信数据进入本 Worker Session；工具事实与资源投影不保存 URL、Cookie 或页面正文。

实际桌面适配器经现有 `ds-bot:browser-endpoint` IPC 获取一次性 CDP 地址，再由 Playwright 连接现有 Electron Host 视图。它复用既有 Host 对导航、存储分区、权限与下载的约束，没有修改 `app/`、`ds-bot/src/client/`、`client.js` 或 DSH。没有桌面 Host IPC 的产品运行时不宣称浏览器可用；测试只注入虚构适配器。

## 验证与未完成项

Node 24.22.1，隔离临时 SQLite、虚构页面、公开 DSH mock Agent 和真实 LocalEnvironment：资源/停止 2 项、产品 Host Main→Router→Worker 1 项通过。覆盖两工作争用同一资源、不同资源 profile 不共用、跨 Instance、无 grant、撤权、停止中取消、未知结果重启后阻塞、人工核查、工作结果工具事实与 Main/Router 工具隔离。相关能力位置、Host 接管、目录、Shell 停止、子代理、MCP 授权及事务契约串行定向回归共 **33/33**；Super-agent build、typecheck、lint 和差异格式检查通过。新增 record kinds 走现有 SQLite/PostgreSQL 共用事务接口；本轮未启动 PostgreSQL 夹具，也未验证真实多进程竞争。

**#110 仍 OPEN**：现有 DS Bot 浏览器面板没有产品资源的选择、用户接管、授权和 `unknown` 操作对账入口；目前操作状态可由受信产品 Host 命令读取，尚不能说面板已展示。#107 的动态浏览器凭据/旧登录态可选导入与完整授权消费仍不足，不能借旧 Bot 登录态补齐。点击、输入、上传、下载、发布等写操作及旧插件的支付/删除/审批保护没有接入新资源，所以 Worker 当前只具备导航与只读快照。尚无真实 Electron/CDP、登录站点、真实模型或完整浏览器验收；Host/CDP 复用仅有代码接缝及 mock 适配器证据。页面读取和导航不能保证消除网站自身的副作用；外部结果未知需人工据实际页面核查，不能自动重试。完整用户面板与凭据/接管行为应在这些依赖接齐后单独验收。
