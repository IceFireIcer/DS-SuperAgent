## 已接通的纵向行为

现有主对话输入增加文件选择、已上传项目与取消入口；每份文件先由受信产品 Host 以命令 ID、Instance、客户端、目录和原始字节摘要登记。图像走 DSH 公开附件准入及规范化，普通文件走 DSH 原样存储；同时将原字节存进本工作目录对应的 Environment asset store。应用消息只保存已准入的 DSH 内容块与有界资源元数据，不把 base64、主机路径或凭据写入 Session、Main 文本及业务投影。仅同一来源、同一目录的未撤销附件可再次引用；重复上传使用原命令 ID 去重，冲突拒绝。产品本地 UI 可按页读取已授权原始字节，撤销后未来引用与读取拒绝；已经接纳的 Session 事实不追溯改写。

Main 调用公开 NativeSessions 时保留原生 `file`/`image` 内容块，重启重试复用持久输入；尚未投递的内容在投递前再次核验撤权，Main 建工前再次核验。WorkBrief 保留未经拼接的用户原文，将 Environment asset 引用另存于 `resources`，只允许在一张附资源的工作项内委托；Router 再拆为多个 Worker 会被拒绝。单个 Worker 可用原执行世界的 `read_asset` 读取原始文件，其原生 Session 也保留获授权图片块。工作卡按 workItemId 从持久投影定位产物，不受最近 20 张卡限制；经原 Environment 身份验证按页读取并下载，猜测路径没有产物可读。远端客户端暂不开放文件管理入口，不能绕过本地 Host 的文件授权。

录入入口沿用现有 `speech.js` 的公开 DSH 语音 Remote、录音与转写函数；没有该服务时复用现有浏览器听写 hook。转写结果先进入原 Main 草稿，确认发送时才分配命令身份。主对话回复沿用现有语音朗读规则与浏览器播放能力，不创建另一套语音服务。

## 定向验证与未完成边界

Node 24 隔离 DSH 附件服务、SQLite 和真实 LocalEnvironment：文件/图像准入、Main/Worker 原生 Session 图片块、Worker `read_asset`、确认产物、工作归属下载、路径猜测拒绝、重放/冲突与撤权覆盖。超过旧 64 KiB 限制的产品上传/产物通过本地专属 8 MiB 上限，Worker 工具原 64 KiB 上限不变；原始字节下载与 Worker 脱敏证据页分开。排队输入在附件撤销后不进入 Main Session，群体拆分在单工作授权模式下被拒绝；客户端丢失上传回执可用同一命令身份重试。相关 DSH NativeSessions 13/13、产品附件 3/3、客户端附件/语音/生成/翻译 27/27；产品 profile 装载含语音 bundle 后的 app/profile/IPC 10/10。未跑全量 CI。

本轮只验证本地桌面产品的文件/图像与录入/播放接缝。外部来源携带附件的保留与授权、多个 Worker 对同条输入的逐项资源授权、上传/发送间全部故障与撤权竞争、原生桌面手工录音/下载、真实模型的图像理解与远端客户端文件传输仍缺独立证据；当前不关闭 #106。业务附件引用的撤销阻止将来接纳和下载，不能宣称撤掉已写入的历史 Session 或已经交给执行中的 Worker 的资源。
