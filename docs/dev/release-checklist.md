# 发版验收清单

本清单用于候选版本。日常票据只运行定向检查；发版时执行完整必需 CI 和平台打包矩阵。每项记录通过、不通过或备注，不通过项附上脱敏日志或截图，并在 Release PR 汇总。

## 构建前

- 在发版 PR 合并前，用已验证的 `dev` 提交构建候选包并做真机检查。发布时确认 tag 指向 `main` 上的合并提交。
- 确认 `superagent/package.json` 与 `app/package.json` 版本一致；应用 ID 为 `io.github.icefireicer.ds-superagent`，产品包为 `ds-superagent`。
- 使用 Node.js 24。测试和打包使用临时 DSH、工作区及数据目录，不指向个人 DSH 或桌面应用的常用数据。
- 自动化检查只用 mock 凭据。日志和制品不得包含真实密钥、令牌、Cookie、租户资料或用户路径。

## 自动化与核心流程

- 发版工作流的所有必需检查、泄漏扫描和平台打包 job 均通过；必需 job 被跳过不算通过。
- 构建并检查唯一的 `ds-superagent` 包；确认 `dsh/client.js` 与 `dsh/office.js` 和源码生成结果一致。
- 使用临时数据启动产品 profile，验证 Main 可创建工作、Router 可分派、Worker 可返回可核验结果。
- 验证原生 Session 写入被拒绝；等待或停止的工作不会显示为已完成；缺少模型、目录或权限时提供明确的修复入口。
- 验证数据隔离和迁移检查不会修改个人 DSH 文件、旧版产品资料或用户选择的目录。

## 桌面交互

| 检查 | 预期 | 结果 |
| --- | --- | --- |
| 拖动标题栏空白处、双击最大化/还原；操作最小化、最大化和关闭 | 窗口操作正常；抽屉、详情面板和浏览器面板不遮挡标题栏按钮 | |
| 将窗口缩至约 900 px 或使用系统分屏 | 侧栏、标题、按钮、输入区不重叠；收起侧栏后可以重新打开 | |
| Windows 显示缩放设为 125% 和 150% | 文字、图标清晰且位置正确；控件和内容没有裁切 | |
| 切换浅色与深色主题 | 文字、图标、窗口按钮和面板均可辨认；系统窗口装饰与页面协调 | |
| 在输入框按 `Enter`、`Shift+Enter`，并用中文输入法组词后按 `Enter` | 前两者分别发送和换行；输入法确认候选字时不会提前发送 | |
| 使用 `Esc`、复制和粘贴 | 对话框、菜单和抽屉可关闭；对话和输入框内复制粘贴可用 | |

## 平台安装包

- **Windows：** 以当前用户安装并首次启动；验证单一 `ds-superagent` profile、Main 工作流程、原位升级和卸载。升级保留产品数据，卸载不删除产品数据或旧版资料。
- **macOS：** 在匹配架构的机器上分别打开 arm64 与 x64 zip，验证首次启动和 Main 工作流程。
- **Linux：** 安装并卸载 deb；在临时副本上运行 AppImage 并验证更新；检查 `ds-superagent` 命令和桌面入口。
- 所有平台确认应用不自动导入或修改个人 DSH 数据及旧版产品文件。

## 外部环境证据

- 仅在属于本次发布范围时记录真实模型、托管 PostgreSQL、远端设备和外部信道的结果，并标明环境、提交及复现步骤。
- 在 Release PR 中列出提交、工作流运行、平台 job、测试摘要和未覆盖的环境验收项。Mock 或本地结果不能代替真实环境证据。
