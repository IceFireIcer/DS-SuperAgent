# DS-SuperAgent 独立演进，移除旧 Bot 架构与兼容义务

2026-11-14，维护者在第三轮设计访谈中明确修正 Q13：新产品已不同于原 ds-bot，旧 Bot 架构去掉即可，不保留旧协作历史入口，不做旧产品兼容。因此新产品不保留长期 Bot 联系人、Main Bot 治理、Bot 互派、群 round、旧 profile 选择/回切、旧客户端协议兼容层或完整旧状态升级要求；保留原前端可用组件，并以 Main → Router → Worker 组织新的协作。

Q11/Q12 同时按推荐确认：旧名称、模型、指令、技能和形象可在审阅后提取为角色预设；记忆、浏览器和凭据可按预览、原归属及明确授权选择导入。这是新产品的可选配置/资源初始化，不恢复旧执行身份、历史 UI 或旧权限。新产品自身的 Main/Router/Worker 历史继续可查；移除旧架构也不授权删除用户磁盘旧数据。

本决定取代此前方案保留旧档案入口、旧协议和旧 profile 兼容的要求，减少双运行时与旧状态耦合；代价是旧客户端、旧私聊/群聊和原数据格式不再是新产品的兼容验收。正式规格中冲突的 D18/D20 等约束需在后续 to-spec 显式更新，本记录不表示产品代码已删除或数据已经导入。
