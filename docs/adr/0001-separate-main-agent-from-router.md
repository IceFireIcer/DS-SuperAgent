# 主 Agent 与 Router 使用独立模型配置和会话上下文

2026-11-14，维护者确认 Main → Router → Worker 的职责关系：Main 是与用户沟通的独立 Agent，拥有自己的模型配置和上下文，将工作委托给 Router；Router 分解和分派工作，Worker Session 执行。分离的目的是让执行细节不占满主 Agent 的对话上下文，同时允许用户通过只读视图查看 Router 与 Worker 的过程；模型配置独立不要求三个角色必须选择不同的模型产品。

设计访谈第一轮的五项推荐已由维护者全部确认：同一授权工作空间维持一条连续主对话，不同隐私范围隔离；Main 可问答、查状态和按需读取有界证据，文件修改、Shell、浏览器操作交给 Worker；外部新的人类请求进入 Main，既有工作跟进和环境事件保持受控直通；完成、失败、需要决定及重要方向变化才主动通知 Main；明确目标的 UI 停止直接交受信核心，不等待模型回合。

第二轮五项推荐也已全部确认：Worker 新增条目不抢焦点且结束后保留历史；明确问题卡的答案直接交受信核心，不等待模型改写；Main 不可用时授权工作继续、持久事实可读、新自然语言输入排队；三层模型/指令通过现有设置页独立配置且不改变在途回合；结果回原请求信道，跨隐私范围分享需明确授权。

第三轮已确认：旧配置可审阅后提取为预设，私有资源按预览和显式授权选择导入；输入框“停止生成”只停止 Main 当前回复，停止工作用目标明确的工作卡。旧架构和兼容范围按 [ADR 0002](0002-independent-product-without-legacy-bot-compatibility.md) 的维护者修正处理。

三轮产品决定已收敛，完整回答见设计访谈记录。以上确认不表示现有运行时已实现三层，也不直接改写现有正式规格。
