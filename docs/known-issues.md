# Known issues

English | [中文](known-issues.zh.md)

No confirmed product issues are listed here at this time.

To report a bug, open an issue in the [DS SuperAgent repository](https://github.com/IceFireIcer/DS-SuperAgent/issues) with the product version, operating system, steps to reproduce and sanitized logs. For security problems, use the repository's **Security → Report a vulnerability** flow instead of a public issue. Do not include secrets or personal data paths.
